## True Pay-Per-Request プロトコル

**主な用途:** 有料の API リクエストやデジタルサービスへのアクセス。

サブスクリプションを必要とせず、個々の API リクエストを支払い対象にできます。支払い条件が満たされると、デジタルレスポンスやサービスが解放されます。

- リクエストまたは利用単位で課金できます。
- リクエスト、決済、デジタル提供を 1 つのフローでつなげます。
- 価格、受取人、利用規約をプロトコルに含めます。

## 決済リンク

**主な用途:** 会話、SNS 投稿、Web サイトからの支払いの受け取り。

決済リンクを作成し、顧客がすでに利用している場所で共有します。顧客はリンクを開いて支払い、あなたは決済ステータスを追跡できます。

- チャット、SNS、Web サイトでリンクを共有できます。
- 商品カタログを作成せずに支払いを受け取れます。
- 入金済みおよび未入金の支払いをリアルタイムで確認できます。

## 商品メニュー

**主な用途:** 商品カタログ、レストランのメニュー、カフェ、小売店のオンラインストア。

商品を 1 ページのオンラインストアにまとめます。顧客はページを移動することなく、メニューを閲覧し、カートに商品を追加して、支払いを完了できます。

- 商品をオンラインメニューに表示できます。
- 閲覧、カート、チェックアウトを 1 か所にまとめます。
- 販売完了時に在庫を自動的に差し引きます。

## POS レジ

**主な用途:** スマートフォンやタブレットを使った対面販売。

専用のレジ端末を購入しなくても、モバイル端末をレジとして利用できます。販売のたびに売上を記録し、在庫を更新します。

- スマートフォンやタブレットで注文と支払いを受け付けられます。
- レジで顧客が選んだ支払い方法に対応します。
- 販売ごとに在庫を自動的に差し引きます。

## 会員・ロイヤルティ

**主な用途:** 支払い時に顧客を会員プログラムへ登録。

顧客の初回決済から会員カードを発行し、顧客が選んだチャネルで届けます。顧客はリンクから PIN の設定と PDPA への同意を自分で行います。

- 決済フローの一部として会員カードを作成できます。
- デジタルカードを顧客に送信します。
- 顧客自身が PIN を設定し、同意を行えます。

## 請求書・料金支払い

**主な用途:** 顧客への請求と未払い分のフォローアップ。

請求書を作成し、顧客に決済リンクを送信します。顧客はオンラインで支払い、あなたはどの請求書が支払い済みで、どれが未払いかを追跡できます。

- 別途手作業で書類を作成することなく、請求書を作成・送信できます。
- オンラインで支払えるリンクを顧客に提供します。
- 決済ステータスをリアルタイムで確認できます。
