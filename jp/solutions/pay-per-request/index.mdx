True Pay-Per-Request プロトコルを使うと、顧客をサブスクリプションに縛ることなく、個々の API リクエストやデジタルサービスの呼び出しに対して課金できます。顧客がリクエストを送信すると支払い条件が評価され、その条件が満たされた時点でデジタルレスポンスやサービスが解放されます。

**主な用途:** 従量制の API アクセス、オンデマンドのデジタルサービス、利用ごとのソフトウェア機能など、顧客が実際にサービスを利用したときだけ支払いたいあらゆるワークフロー。

## 仕組み

1. リクエストの価格、受取人、利用規約を定義します。
2. API リクエスト、決済、デジタル提供を 1 つのフローでつなげます。
3. 支払い条件が満たされると、デジタルレスポンスやサービスを解放します。

## 最低限の準備

リクエスト単位の支払いの受け付けを開始する前に、以下を準備してください。

- 課金対象とする API またはデジタルサービス。
- 顧客に請求するリクエストごとまたは利用ごとの価格。
- 提供するサービスの受取人と利用規約。

アカウント要件と利用資格については、[hello@feezless.cloud](mailto:hello@feezless.cloud) までお問い合わせください。

## 料金

顧客にリクエストごとに請求する価格と、Feezless の利用手数料は区別してください。支払いを受け付ける前に、最新の取引手数料率と適用される料金について Feezless にお問い合わせください。

> **注:** 支払いリクエストの作成や振込証明の受領だけでは、支払いは確定しません。デジタルレスポンスやサービスを提供する前に、確定済みの決済ステータスを確認してください。

## 次のステップ

API やデジタルサービスに True Pay-Per-Request プロトコルを導入するには、ユースケース、想定されるリクエスト量、リクエストごとに請求する予定の価格を添えて、[hello@feezless.cloud](mailto:hello@feezless.cloud) までお問い合わせください。
