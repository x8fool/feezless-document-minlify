店頭販売システム (POS Cashier) を使うと、専用のレジ端末を購入することなく、スマートフォンやタブレットから直接、店頭の注文と支払いを受け付けられます。取引を完了するたびに、売上が記録され、在庫が自動的に更新されます。

## 主な用途

- カウンター、屋台、ポップアップストアでの店頭販売
- 固定の決済端末を使いにくい場合のモバイル決済
- 店頭の売上に合わせた在庫の更新

## 仕組み

1. 販売する商品と価格を設定します。
2. 注文を受け、スマートフォンやタブレットで顧客に決済画面を提示します。
3. 顧客が決済画面で支払い方法を選択します。
4. 販売が完了すると、在庫が自動的に差し引かれます。

> **注:** 決済の作成や振込証明の送信だけでは、支払いは確定しません。商品やサービスを引き渡す前に、確定済みの決済ステータスを確認してください。

## 準備するもの

利用を開始する前に、以下を準備してください。

- レジ画面として使用するスマートフォンまたはタブレット
- 販売する商品と価格の一覧

アカウント開設の要件と申込者の資格については、[お問い合わせフォーム](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1) よりご連絡ください。

## 料金

支払いの受け取りを開始する前に、最新の取引手数料率と関連する費用について [Feezless にお問い合わせください。](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)

### 料金計算の例

あくまで説明用の例として：

| 項目 | 金額 |
| --- | --- |
| 決済金額 | 1,000 通貨単位 |
| 料率 | 0.8% |
| 手数料 | 1,000 x 0.8 / 100 = 8 通貨単位 |
| この手数料のみを差し引いた残高 | 1,000 - 8 = 992 通貨単位 |

これは承認済みの料率ではありません。利用開始前に実際の料率を [Feezless にご確認ください。](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1) 税金やその他の費用は含まれておらず、決済確定金額ではありません。

## 販売チャネルを選ぶ

店頭販売システムは、店頭での顧客への販売向けに設計されています。顧客がオンラインで商品を閲覧して支払えるようにもしたい場合は、[商品メニュー (Product Menu)](/jp/solutions/product-menu/index) を使って、ストア、カート、決済を 1 ページにまとめましょう。

設定や料金に関するご質問は、ユースケースを添えて [お問い合わせフォーム](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1) よりご連絡ください。

export const PricingCalculator = () => {
  const [amount, setAmount] = useState("1000");
  const rateText = "0.8";
  const value = Number(amount);
  const percent = Number(rateText);
  const fee = value * (percent / 100);
  const remainder = value - fee;
  const valid = amount.trim() !== "" && Number.isFinite(value) && value >= 0 && Number.isFinite(percent) && percent >= 0 && Number.isFinite(fee) && Number.isFinite(remainder);
  const format = (n) => n.toLocaleString("ja-JP", { minimumFractionDigits: 2, maximumFractionDigits: 2 });
  return (
    <div className="not-prose" style={{ width: "100%", boxSizing: "border-box", border: "1px solid rgba(127,127,127,.25)", borderRadius: 12, padding: 16, background: "transparent", color: "inherit" }}>
      <div style={{ display: "grid", gap: 12 }}>
        <label style={{ display: "grid", gap: 4, fontSize: 14, color: "inherit" }}>
          決済金額（通貨単位）
          <input type="number" min="0" step="any" value={amount} onChange={(e) => setAmount(e.target.value)} style={{ minWidth: 0, width: "100%", boxSizing: "border-box", padding: "8px 10px", borderRadius: 8, border: "1px solid rgba(127,127,127,.35)", background: "transparent", color: "inherit", font: "inherit" }} />
        </label>
        <div style={{ fontSize: 14 }}>固定の説明用例の料率: 0.8%（承認済みの料率ではありません）</div>
        <div aria-live="polite" style={{ fontSize: 14 }}>
          {valid ? (
            <div style={{ display: "grid", gap: 4 }}>
              <div>手数料（この手数料のみ）: {format(fee)} 通貨単位</div>
              <div>この手数料を差し引いた残り: {format(remainder)} 通貨単位</div>
            </div>
          ) : (
            <div>有効な決済金額を入力してください</div>
          )}
        </div>
        <div style={{ fontSize: 12, opacity: 0.7 }}>税金やその他の追加の手数料がかかる場合があります。小数点第2位までの表示は参考であり、決済見積ではありません。</div>
      </div>
    </div>
  );
};
