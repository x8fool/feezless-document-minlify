### 1. การยอมรับข้อกำหนด

เมื่อคุณกดยอมรับ สมัครใช้งาน หรือใช้บริการของ Feezless ถือว่าคุณได้อ่าน เข้าใจ และตกลงผูกพันตามข้อกำหนดการใช้งานฉบับนี้ หากคุณไม่ยอมรับ โปรดหยุดใช้บริการ

หากคุณใช้บริการในนามนิติบุคคล คุณรับรองว่ามีอำนาจผูกพันนิติบุคคลนั้นตามข้อกำหนดนี้

### 2. บริการที่ครอบคลุม

ข้อกำหนดนี้ใช้กับบริการของ Feezless ได้แก่ การชำระเงินต่อคำขอ (Pay-Per-Request) ลิงก์ชำระเงิน (Payment Link) เมนูสินค้า ระบบขายหน้าร้าน (POS) ระบบสมาชิกและสิทธิประโยชน์ ใบแจ้งหนี้และการชำระบิล ระบบตรวจสอบสลิปอัตโนมัติ รวมถึงเว็บไซต์ API สำหรับการทำธุรกรรมและการชำระเงินอิเล็กทรอนิกส์ และเอกสารที่เกี่ยวข้อง

บริการแต่ละประเภทอาจมีเงื่อนไขเฉพาะเพิ่มเติม หากขัดแย้งกัน ให้ใช้เงื่อนไขเฉพาะของบริการนั้นก่อน

### 3. บัญชีและข้อมูลรับรองการเข้าถึง

- คุณต้องให้ข้อมูลที่ถูกต้อง ครบถ้วน และเป็นปัจจุบันเมื่อเปิดบัญชีและตลอดการใช้งาน
- เก็บรักษาข้อมูลรับรอง เช่น API key, secret key และรหัสผ่าน ไว้ฝั่งเซิร์ฟเวอร์อย่างปลอดภัย ห้ามฝังไว้ในแอปฝั่งลูกค้า
- แจ้ง Feezless ทันทีเมื่อสงสัยว่าข้อมูลรับรองรั่วไหล คุณต้องรับผิดชอบการใช้งานที่เกิดจากข้อมูลรับรองของคุณ

### 4. การใช้งานที่ยอมรับได้

คุณตกลงว่าจะไม่:

- ใช้บริการเพื่อธุรกรรมที่ผิดกฎหมาย ฉ้อโกง ฟอกเงิน หรือสนับสนุนการก่อการร้าย
- พยายามเข้าถึงระบบ ข้อมูล หรือบัญชีที่ไม่ได้รับอนุญาต หรือหลีกเลี่ยงกลไกด้านความปลอดภัย
- ส่งคำขอในปริมาณที่ก่อให้เกิดภาระเกินควร หรือรบกวนการทำงานของบริการ
- ข้ามขั้นตอนการตรวจสอบลายเซ็น (signature) หรือการยืนยันการชำระเงินที่บริการกำหนด

### 5. การชำระเงินและค่าบริการ

ค่าบริการและอัตราค่าธรรมเนียมตกลงและแจ้งผ่านเว็บไซต์ ข้อตกลงการใช้บริการ หรือแพ็กเกจรายเดือนหรือรายธุรกรรมที่คุณเลือก รวมถึงข้อตกลงหรือใบเสนอราคาที่ Feezless แจ้งให้คุณ

การสร้างลิงก์ชำระเงินหรือได้รับคำตอบ HTTP 200 จากการสร้างรายการ ไม่ได้หมายความว่าการชำระเงินสำเร็จ ให้ยืนยันผลจากสถานะธุรกรรมหรือ Webhook ที่ตรวจสอบลายเซ็นแล้วเท่านั้น

#### การคืนค่าบริการและการยกเลิกแพ็กเกจ

- ค่าบริการแพ็กเกจรายเดือนไม่สามารถขอคืนได้ เว้นแต่มีข้อผิดพลาดโดยตรงจากระบบของ Feezless
- ส่งคำขอคืนค่าบริการไปที่ [hello@feezless.cloud](mailto:hello@feezless.cloud) ภายใน 7 วันทำการหลังพบข้อผิดพลาด ระยะเวลานี้เป็นกำหนดยื่นคำขอ ไม่ใช่กำหนดเวลาที่รับประกันว่าจะคืนเงินเสร็จสิ้น
- ทีมบริหารและฝ่ายการเงินของ Feezless เป็นผู้พิจารณาอนุมัติและดำเนินการคืนค่าบริการ
- ร้านค้าสามารถแจ้งยกเลิกการใช้บริการล่วงหน้าตามรอบบิลโดยไม่มีค่าธรรมเนียมปรับ การยกเลิกไม่ทำให้เกิดสิทธิคืนค่าบริการนอกเหนือจากเงื่อนไขข้างต้น

#### ข้อพิพาทธุรกรรมและการคืนเงินให้ลูกค้า

ระบบรับชำระแบบ Direct-to-Merchant โอนเงินตรงเข้าบัญชีร้านค้า ข้อพิพาทเรื่องยอดเงิน การโต้แย้งรายการ หรือการคืนเงินค่าสินค้าและบริการให้ลูกค้า เป็นความรับผิดชอบของร้านค้าที่ต้องจัดการโดยตรงกับลูกค้า ร้านค้ารับผิดชอบค่าธรรมเนียมหรือความเสียหายที่เกิดจากข้อพิพาทธุรกรรมของตนเอง

#### การโอนเงินเข้าร้านค้า

สำหรับการรับชำระแบบ Direct-to-Merchant เงินโอนตรงเข้าบัญชีร้านค้าแบบเรียลไทม์ผ่านการสแกนจ่ายหรือโอนตรง การโอนอาจล่าช้าหรือถูกระงับเมื่อระบบธนาคารขัดข้อง หรือพบธุรกรรมต้องสงสัยว่าเข้าข่ายผิดกฎหมาย จึงไม่ถือเป็นการรับประกันว่าเงินจะเข้าทันทีในทุกกรณี

### 6. ข้อมูลส่วนบุคคล

การเก็บ ใช้ และเปิดเผยข้อมูลส่วนบุคคลเป็นไปตาม [นโยบายความเป็นส่วนตัว](/th/legal/privacy-policy) และพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

หากคุณเก็บข้อมูลลูกค้าของคุณผ่านบริการ คุณมีหน้าที่แจ้งวัตถุประสงค์และขอความยินยอมจากลูกค้าตามที่กฎหมายกำหนด

### 7. ทรัพย์สินทางปัญญา

ซอฟต์แวร์ API เอกสาร เครื่องหมายการค้า และเนื้อหาของ Feezless เป็นทรัพย์สินของห้างหุ้นส่วนสามัญนิติบุคคล ฟีซเลส คุณได้รับสิทธิใช้งานแบบไม่ผูกขาดและเพิกถอนได้ เพื่อใช้บริการตามข้อกำหนดนี้เท่านั้น

### 8. การระงับและยกเลิกบริการ

Feezless อาจระงับหรือยกเลิกบริการเมื่อคุณฝ่าฝืนข้อตกลง ใช้ระบบกระทำผิดกฎหมาย หรือค้างชำระค่าบริการแพ็กเกจ โดยแจ้งเตือนล่วงหน้า 7 วัน เว้นแต่เป็นกรณีร้ายแรง เช่น การโจมตีระบบ การทุจริต หรือคำสั่งจากหน่วยงานรัฐ ซึ่งอาจระงับบริการได้ทันที

คุณสามารถขอปิดบัญชีผ่านหน้าตั้งค่าบัญชี หรือส่งอีเมลไปที่ [hello@feezless.cloud](mailto:hello@feezless.cloud) โดยต้องชำระค่าบริการระบบที่ค้างอยู่ให้เรียบร้อยก่อนปิดบัญชีอย่างสมบูรณ์

ร้านค้าสามารถขอส่งออกข้อมูลประวัติธุรกรรมที่จำเป็นในช่วง 30 วันก่อนปิดบัญชีถาวร ข้อกำหนดนี้ไม่ได้รับประกันการเข้าถึงหรือส่งออกข้อมูลหลังปิดบัญชีถาวรแล้ว การเก็บรักษาข้อมูลที่กฎหมายกำหนดภายหลังปิดบัญชีเป็นไปตามนโยบายความเป็นส่วนตัว

### 9. การจำกัดความรับผิด

Feezless ให้บริการในลักษณะ "ตามที่เป็นอยู่" (As-Is) โดยมุ่งมั่นรักษาเสถียรภาพของระบบให้ดีที่สุด

ภายใต้ขอบเขตที่กฎหมายอนุญาต ความรับผิดสูงสุดของ Feezless จะไม่เกินจำนวนค่าบริการที่ร้านค้าชำระให้ Feezless ในช่วง 3 เดือนที่ผ่านมา ข้อกำหนดนี้ไม่ตัดสิทธิหรือยกเว้นความรับผิดที่กฎหมายไม่อนุญาตให้จำกัดหรือยกเว้น
