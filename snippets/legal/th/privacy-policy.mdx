### 1. ขอบเขตของนโยบาย

นโยบายนี้อธิบายวิธีที่ Feezless เก็บ ใช้ เปิดเผย และคุ้มครองข้อมูลส่วนบุคคลของคุณ เมื่อคุณใช้เว็บไซต์ API และบริการของ Feezless ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) ครอบคลุมระบบซอฟต์แวร์บริหารจัดการร้านค้า (POS) ระบบสร้างลิงก์ชำระเงิน (Payment Link) ระบบตรวจสอบสลิปอัตโนมัติ และโครงสร้างพื้นฐาน API สำหรับการทำธุรกรรมและการชำระเงินอิเล็กทรอนิกส์

- **ผู้ควบคุมข้อมูลส่วนบุคคล:** Feezless กำหนดวัตถุประสงค์และวิธีการใช้ข้อมูลสำหรับการบริหารบัญชีผู้ใช้งานแพลตฟอร์ม การเก็บบันทึกประวัติการใช้งานระบบ และการทำตลาดของ Feezless เอง
- **ผู้ประมวลผลข้อมูลส่วนบุคคล:** Feezless ประมวลผลข้อมูลธุรกรรม ข้อมูลลูกค้าของร้านค้า และข้อมูลคำสั่งซื้อที่ร้านค้าส่งผ่าน POS และ Payment Link ตามคำสั่งของร้านค้า โดยร้านค้าเป็นผู้ควบคุมข้อมูลสำหรับกิจกรรมดังกล่าว

### 4. การเปิดเผยข้อมูล

เราอาจเปิดเผยข้อมูลของคุณให้แก่:

- ร้านค้าที่คุณทำธุรกรรมด้วย เฉพาะข้อมูลการชำระเงินและคำสั่งซื้อที่จำเป็นต่อการจัดส่งสินค้าและให้บริการของร้านค้านั้น
- ธนาคารพาณิชย์และผู้ให้บริการชำระเงินที่เชื่อมต่อระบบ เช่น ธนาคารกสิกรไทย สำหรับการตรวจสอบสลิปและรับชำระเงินตามบริการที่ใช้งาน
- ผู้ให้บริการ Cloud Server, Hosting และพื้นที่จัดเก็บข้อมูลที่มีมาตรการรักษาความมั่นคงปลอดภัย
- หน่วยงานรัฐหรือหน่วยงานกำกับดูแล เมื่อกฎหมายกำหนด

### 5. สถานที่จัดเก็บและการส่งข้อมูลไปต่างประเทศ

ข้อมูลจัดเก็บหรือเข้าถึงในประเทศไทย และอาจใช้ผู้ให้บริการ Cloud ที่มีมาตรฐานความปลอดภัยสากล หากมีการส่งหรือโอนข้อมูลข้ามพรมแดน เราใช้การเข้ารหัสข้อมูลและสัญญาประมวลผลข้อมูลเป็นมาตรการคุ้มครอง

รายชื่อผู้ให้บริการ Cloud และประเทศปลายทางนอกประเทศไทยยังอยู่ระหว่างการยืนยันก่อนใช้งานนโยบายฉบับสมบูรณ์ มาตรฐานความปลอดภัยของผู้ให้บริการไม่ใช่การระบุประเทศที่จัดเก็บหรือเข้าถึงข้อมูล

### 6. ระยะเวลาเก็บรักษา

| ประเภทข้อมูล | ระยะเวลาเก็บรักษา |
| --- | --- |
| บัญชีและข้อมูลติดต่อ | ตลอดอายุบัญชี และไม่เกิน 5 ปีหลังปิดบัญชี |
| ธุรกรรมและเอกสารทางบัญชี | 5 ถึง 10 ปี ตามข้อกำหนดของกฎหมายบัญชีและภาษีอากรไทยที่ใช้กับเอกสารนั้น |
| ข้อมูลสมาชิก | ตลอดอายุการเป็นสมาชิกหรือจนกว่าจะมีคำขอลบข้อมูล ทั้งนี้อยู่ภายใต้ข้อยกเว้นตามกฎหมาย |
| สลิปและเอกสารที่อัปโหลด | 1 ถึง 5 ปี ตามรอบระยะเวลาทางบัญชีและความจำเป็นในการตรวจสอบธุรกรรม |
| บันทึกความปลอดภัยและ API | 90 วันถึง 1 ปี ตามความจำเป็นด้านความปลอดภัยทางคอมพิวเตอร์ |
| บันทึกความยินยอม | ตลอดระยะเวลาที่ความยินยอมมีผล และอีก 3 ปีหลังเพิกถอนเพื่อเก็บไว้เป็นหลักฐาน |
| ข้อมูลสำรอง | ตามรอบการหมุนเวียนข้อมูลสำรองของระบบ Cloud โดยรอบเวลาที่แน่นอนยังอยู่ระหว่างการยืนยัน |

เมื่อพ้นระยะเวลาเก็บรักษา เราจะลบ ทำลาย หรือทำให้ข้อมูลเป็นนิรนามอย่างถาวร หลังปิดบัญชี ข้อมูลทางบัญชี ธุรกรรม และบันทึกที่กฎหมายกำหนดอาจยังคงเก็บไว้เพื่อการตรวจสอบทางภาษีและกฎหมาย

### 7. ความปลอดภัยของข้อมูล

- จัดเก็บรหัส PIN ด้วยการแฮชแบบทางเดียวร่วมกับ Salt ไม่จัดเก็บหรืออนุญาตให้อ่าน PIN เป็นข้อความธรรมดา (Plaintext)
- ใช้ HTTPS/TLS เพื่อคุ้มครองข้อมูลระหว่างรับส่ง
- จำกัดสิทธิ์การเข้าถึงฐานข้อมูลตามหน้าที่
- ตรวจสอบช่องโหว่ของระบบ API

### 8. สิทธิของเจ้าของข้อมูล

คุณมีสิทธิตาม PDPA ดังนี้:

- ขอเข้าถึงและขอรับสำเนาข้อมูล
- ขอแก้ไขข้อมูลให้ถูกต้องและเป็นปัจจุบัน
- ขอลบ ทำลาย หรือทำให้ข้อมูลไม่สามารถระบุตัวตนได้
- ขอระงับการใช้ข้อมูล
- คัดค้านการเก็บ ใช้ หรือเปิดเผยข้อมูล
- ขอโอนย้ายข้อมูล
- ถอนความยินยอมได้ทุกเมื่อ โดยไม่กระทบการประมวลผลที่ทำไปแล้วก่อนถอน
- ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล
