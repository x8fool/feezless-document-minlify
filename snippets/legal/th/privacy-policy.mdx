### 1. ขอบเขตของนโยบาย

นโยบายนี้อธิบายวิธีที่ Feezless เก็บ ใช้ เปิดเผย และคุ้มครองข้อมูลส่วนบุคคลของคุณ เมื่อคุณใช้เว็บไซต์ API และบริการของ Feezless ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

`[ระบุบทบาทของ Feezless ในแต่ละบริการ ว่าเป็นผู้ควบคุมข้อมูลหรือผู้ประมวลผลข้อมูลแทนร้านค้า]`

### 2. ข้อมูลที่เราเก็บ

| ประเภท | ตัวอย่าง |
| --- | --- |
| ข้อมูลระบุตัวตนและติดต่อ | ชื่อ นามสกุล เบอร์โทรศัพท์ อีเมล |
| ข้อมูลธุรกรรม | หมายเลขอ้างอิงรายการ จำนวนเงิน สกุลเงิน วันเวลา สถานะการชำระเงิน |
| ข้อมูลสมาชิก | หมายเลขสมาชิก ประวัติสิทธิประโยชน์ บันทึกการให้ความยินยอม |
| ข้อมูลทางเทคนิค | IP address ประเภทอุปกรณ์และเบราว์เซอร์ บันทึกการเรียกใช้ API |
| หลักฐานการโอนเงิน | ไฟล์สลิปหรือเอกสารที่คุณอัปโหลด |

เราไม่เก็บรหัส PIN ในรูปแบบข้อความที่อ่านได้ `[ยืนยันวิธีจัดเก็บกับทีมวิศวกรรม]`

### 3. วัตถุประสงค์และฐานทางกฎหมาย

| วัตถุประสงค์ | ฐานทางกฎหมาย |
| --- | --- |
| ประมวลผลการชำระเงินและให้บริการตามที่คุณร้องขอ | การปฏิบัติตามสัญญา |
| ป้องกันการทุจริตและรักษาความปลอดภัยของระบบ | ประโยชน์โดยชอบด้วยกฎหมาย |
| ปฏิบัติตามกฎหมาย เช่น บัญชี ภาษี และการป้องกันการฟอกเงิน | หน้าที่ตามกฎหมาย |
| สมัครสมาชิก ส่งบัตรสมาชิก และให้สิทธิประโยชน์ | ความยินยอม หรือการปฏิบัติตามสัญญา |
| ส่งข่าวสารและข้อเสนอทางการตลาด | ความยินยอม |

### 4. การเปิดเผยข้อมูล

เราอาจเปิดเผยข้อมูลของคุณให้แก่:

- ร้านค้าที่คุณทำธุรกรรมด้วย เฉพาะเท่าที่จำเป็นต่อการให้บริการ
- ธนาคาร ผู้ให้บริการชำระเงิน และผู้ให้บริการที่ประมวลผลข้อมูลแทนเรา
- หน่วยงานรัฐหรือหน่วยงานกำกับดูแล เมื่อกฎหมายกำหนด

`[รายชื่อหรือประเภทผู้รับข้อมูลเพิ่มเติม]`

### 5. การส่งข้อมูลไปต่างประเทศ

`[ระบุประเทศปลายทางและมาตรการคุ้มครองที่ใช้ หากมีการส่งหรือโอนข้อมูลไปต่างประเทศ]`

### 6. ระยะเวลาเก็บรักษา

เราเก็บข้อมูลเท่าที่จำเป็นตามวัตถุประสงค์ และตามระยะเวลาที่กฎหมายกำหนด `[ระยะเวลาเก็บรักษาแยกตามประเภทข้อมูล]` เมื่อพ้นระยะเวลา เราจะลบ ทำลาย หรือทำให้ข้อมูลไม่สามารถระบุตัวตนได้

### 7. ความปลอดภัยของข้อมูล

เราใช้มาตรการด้านเทคนิคและการบริหารจัดการที่เหมาะสม เช่น การเข้ารหัสระหว่างส่งผ่าน HTTPS การควบคุมสิทธิ์เข้าถึง และการตรวจสอบลายเซ็นของข้อมูล `[มาตรการเพิ่มเติม]`

### 8. สิทธิของเจ้าของข้อมูล

คุณมีสิทธิตาม PDPA ดังนี้:

- ขอเข้าถึงและขอรับสำเนาข้อมูล
- ขอแก้ไขข้อมูลให้ถูกต้องและเป็นปัจจุบัน
- ขอลบ ทำลาย หรือทำให้ข้อมูลไม่สามารถระบุตัวตนได้
- ขอระงับการใช้ข้อมูล
- คัดค้านการเก็บ ใช้ หรือเปิดเผยข้อมูล
- ขอโอนย้ายข้อมูล
- ถอนความยินยอมได้ทุกเมื่อ โดยไม่กระทบการประมวลผลที่ทำไปแล้วก่อนถอน
- ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล

ใช้สิทธิได้โดยติดต่อช่องทางในหัวข้อ "ติดต่อเรา" เราจะตอบกลับภายใน `[ระยะเวลา]`
