ระบบขายหน้าร้าน (POS Cashier) ให้คุณรับคำสั่งซื้อและชำระเงินผ่านโทรศัพท์หรือแท็บเล็ต โดยไม่ต้องซื้อเครื่องคิดเงินเฉพาะทาง เมื่อรายการเสร็จสมบูรณ์ ระบบจะบันทึกยอดขายและอัปเดตสต็อกอัตโนมัติ

## เหมาะสำหรับ

- การขายหน้าร้านที่เคาน์เตอร์ แผงขายสินค้า หรือจุดขายชั่วคราว
- การรับชำระเงินแบบเคลื่อนที่ เมื่อไม่สะดวกใช้เครื่องชำระเงินประจำจุด
- การอัปเดตสต็อกให้ตรงกับยอดขายหน้าร้าน

## วิธีการทำงาน

1. ตั้งค่ารายการสินค้าและราคาที่ต้องการขาย
2. รับคำสั่งซื้อและแสดงหน้าชำระเงินให้ลูกค้าบนโทรศัพท์หรือแท็บเล็ตของคุณ
3. ลูกค้าเลือกวิธีชำระเงินที่หน้าชำระเงิน
4. ระบบตัดสต็อกอัตโนมัติเมื่อการขายเสร็จสมบูรณ์

ดูเส้นทางลูกค้าตั้งแต่เลือกซื้อจนถึงรับสินค้า โดยเลือกจุดบนเส้นขั้นตอนด้านล่าง ภาพนี้เป็นภาพประกอบ ไม่ใช่หน้าจอหรือสถานะธุรกรรมจริง

        <span aria-hidden="true" style={{ fontSize: 12, opacity: .7 }}>{active + 1} / {steps.length}</span>
        <button type="button" style={btn} disabled={active === steps.length - 1} onClick={() => setActive((value) => Math.min(steps.length - 1, value + 1))} aria-label="ถัดไป" title="ถัดไป"><Icon icon="chevron-right" size={16} /></button>
      </div>
    </section>
  );
};
