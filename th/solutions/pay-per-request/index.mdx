โปรโตคอลชำระเงินต่อคำขอ (True Pay-Per-Request Protocol) คิดค่าบริการแยกตามคำขอ API หรือการเรียกใช้บริการดิจิทัล ลูกค้าจ่ายเฉพาะที่ใช้ ไม่ต้องสมัครสมาชิกแบบเหมาจ่าย เมื่อส่งคำขอ ระบบตรวจสอบเงื่อนไขการชำระเงิน และเปิดให้เข้าถึงผลลัพธ์หรือบริการดิจิทัลเมื่อเป็นไปตามเงื่อนไข

**เหมาะสำหรับ:** API ที่คิดค่าบริการตามปริมาณการใช้งาน บริการดิจิทัลแบบเรียกใช้เมื่อต้องการ ฟังก์ชันซอฟต์แวร์ที่คิดค่าบริการต่อครั้ง และรูปแบบการใช้งานที่ลูกค้าจ่ายเฉพาะเมื่อใช้บริการจริง

## วิธีการทำงาน

1. กำหนดราคา ผู้รับเงิน และเงื่อนไขการใช้บริการสำหรับคำขอ
2. เชื่อมคำขอ API การชำระเงิน และการส่งมอบบริการดิจิทัลไว้ในขั้นตอนเดียวกัน
3. เปิดให้เข้าถึงผลลัพธ์หรือบริการดิจิทัลเมื่อเป็นไปตามเงื่อนไขการชำระเงิน

## สิ่งที่ต้องเตรียม

เตรียมข้อมูลต่อไปนี้ก่อนเริ่มใช้งาน:

- API หรือบริการดิจิทัลที่ต้องการคิดค่าบริการ
- ราคาต่อคำขอหรือต่อการใช้งานที่จะเรียกเก็บจากลูกค้า
- ข้อมูลผู้รับเงินและเงื่อนไขการใช้บริการ

## ค่าบริการ

ราคาที่เรียกเก็บจากลูกค้าต่อคำขอแยกจากค่าธรรมเนียมการใช้ Feezless ติดต่อ [Feezless](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1) เพื่อสอบถามอัตราค่าธรรมเนียมธุรกรรมและค่าใช้จ่ายที่เกี่ยวข้องในปัจจุบันก่อนเริ่มรับชำระเงิน

### ตัวอย่างการคำนวณค่าบริการ

สมมติว่าลูกค้าชำระเงินสำหรับคำขอ API หนึ่งรายการ 1,000 หน่วยเงิน ยอดนี้ใช้แสดงวิธีคำนวณเท่านั้น ไม่ใช่ราคาต่อคำขอหรือค่าบริการที่ Feezless กำหนด

เอกสารยังไม่ได้ระบุอัตราค่าธรรมเนียมเป็นตัวเลขสำหรับบริการนี้ **หาก Feezless ยืนยันว่าคิดค่าธรรมเนียมแบบเปอร์เซ็นต์ที่อัตรา r%** จึงใช้สูตรต่อไปนี้ได้ โดย r แทนอัตราที่ได้รับการยืนยัน ไม่ใช่อัตราที่สมมติขึ้น

| รายการ | วิธีคำนวณ | จำนวนหน่วยเงิน |
| --- | --- | --- |
| ยอดชำระตัวอย่าง | 1 รายการ | 1,000 |
| ค่าธรรมเนียมแบบเปอร์เซ็นต์ หากใช้กับบัญชีของคุณ | 1,000 × r ÷ 100 | 10r |
| ยอดคงเหลือหลังหักเฉพาะค่าธรรมเนียมนี้ | 1,000 − 10r | ต้องทราบ r ก่อน |

กรอกอัตราที่ Feezless ยืนยันในเครื่องคำนวณเฉพาะเมื่อใช้การคิดค่าธรรมเนียมแบบเปอร์เซ็นต์ ตารางและเครื่องคำนวณไม่รวมภาษีหรือค่าใช้จ่ายอื่นที่อาจมี และไม่ใช่การยืนยันยอดที่จะได้รับจริง การแสดงทศนิยมสองตำแหน่งมีไว้ประกอบตัวอย่าง ไม่ใช่นโยบายการปัดเศษของ Feezless
