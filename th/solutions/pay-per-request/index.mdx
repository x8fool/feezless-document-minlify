โปรโตคอลชำระเงินต่อคำขอ (True Pay-Per-Request Protocol) ช่วยให้คุณคิดค่าบริการแยกตามคำขอ API หรือการเรียกใช้บริการดิจิทัล แทนการบังคับให้ลูกค้าสมัครสมาชิกแบบเหมาจ่าย เมื่อลูกค้าส่งคำขอ ระบบจะตรวจสอบเงื่อนไขการชำระเงิน และเปิดให้เข้าถึงผลลัพธ์หรือบริการดิจิทัลเมื่อเป็นไปตามเงื่อนไข

**เหมาะสำหรับ:** การเข้าถึง API แบบคิดค่าบริการตามปริมาณการใช้งาน บริการดิจิทัลแบบเรียกใช้เมื่อต้องการ ฟังก์ชันซอฟต์แวร์ที่คิดค่าบริการต่อครั้ง และรูปแบบการใช้งานที่ลูกค้าต้องการจ่ายเฉพาะเมื่อใช้บริการจริง

## วิธีการทำงาน

1. กำหนดราคา ผู้รับเงิน และเงื่อนไขการใช้บริการสำหรับคำขอ
2. เชื่อมคำขอ API การชำระเงิน และการส่งมอบบริการดิจิทัลไว้ในขั้นตอนเดียวกัน
3. เปิดให้เข้าถึงผลลัพธ์หรือบริการดิจิทัลเมื่อเป็นไปตามเงื่อนไขการชำระเงิน

## สิ่งที่ต้องเตรียม

ก่อนเริ่มรับชำระเงินต่อคำขอ ให้เตรียมข้อมูลต่อไปนี้:

- API หรือบริการดิจิทัลที่ต้องการคิดค่าบริการ
- ราคาต่อคำขอหรือต่อการใช้งานที่จะเรียกเก็บจากลูกค้า
- ข้อมูลผู้รับเงินและเงื่อนไขการใช้บริการ

ติดต่อ [hello@feezless.cloud](mailto:hello@feezless.cloud) เพื่อสอบถามข้อกำหนดการเปิดบัญชีและคุณสมบัติของผู้สมัคร

## ค่าบริการ

แยกราคาที่คุณเรียกเก็บจากลูกค้าต่อคำขอออกจากค่าธรรมเนียมการใช้ Feezless ติดต่อ Feezless เพื่อสอบถามอัตราค่าธรรมเนียมธุรกรรมและค่าใช้จ่ายที่เกี่ยวข้องในปัจจุบันก่อนเริ่มรับชำระเงิน

> **หมายเหตุ:** การสร้างคำขอชำระเงินหรือการได้รับหลักฐานการโอนเงินเพียงอย่างเดียวไม่ใช่การยืนยันว่าชำระเงินแล้ว ตรวจสอบสถานะการชำระเงินที่ยืนยันแล้วก่อนส่งมอบผลลัพธ์หรือบริการดิจิทัล

## ขั้นตอนถัดไป

กรอกแบบฟอร์มเพื่อให้ทีม Feezless ติดต่อกลับเรื่องการตั้งค่าโปรโตคอลชำระเงินต่อคำขอสำหรับ API หรือบริการดิจิทัลของคุณ พร้อมระบุลักษณะการใช้งาน ปริมาณคำขอที่คาดการณ์ไว้ และราคาที่วางแผนจะเรียกเก็บต่อคำขอ
