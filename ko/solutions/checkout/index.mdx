결제 링크(Checkout Cart)를 사용하면 상품 카탈로그나 온라인 스토어를 만들지 않고도 고객이 이미 사용하는 채널로 링크를 공유하여 결제를 받을 수 있습니다. 고객이 링크를 열어 결제하면, 수납 완료 금액과 미수 금액을 실시간으로 추적할 수 있습니다.

**활용 사례:** 대화, 소셜 미디어 게시물, 웹사이트 등 링크를 직접 보내는 것이 가장 빠른 결제 수납 방법인 채널에서 결제 수납

## 작동 방식

1. 청구할 금액으로 결제 링크를 생성합니다.
2. 채팅, 소셜 미디어 게시물 또는 웹사이트를 통해 링크를 공유합니다.
3. 고객이 링크를 열고 결제합니다.
4. 수납 완료 금액과 미수 금액을 실시간으로 추적합니다.

## 준비 사항

결제 수납을 시작하기 전에 다음 정보를 준비하세요.

- 청구할 금액과 항목 설명
- 채팅, 소셜 미디어, 웹사이트 등 고객에게 링크를 보낼 채널

계정 개설 요건 및 신청 자격은 [Feezless에 문의](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)하세요.

## 요금

결제 수납을 시작하기 전에 현재 거래 수수료율과 관련 비용을 [Feezless에 문의](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)하세요.

### 요금 계산 예시

아래 수치는 이해를 돕기 위한 예시이며 승인된 요율이 아닙니다.

- 결제 금액(예시): 1,000 통화 단위
- 고정 예시 수수료율(승인되지 않음): 2.0%
- 수수료: 1,000 x 2.0 / 100 = 20 통화 단위
- 이 수수료를 제외한 남은 금액: 1,000 - 20 = 980 통화 단위

아래 예시와 계산기는 세금 및 기타 가능한 부가 비용을 포함하지 않으며, 정산 견적서가 아닙니다. 표시되는 소수점 둘째 자리까지의 값은 예시를 위한 것이며 Feezless의 반올림 기준과 다를 수 있습니다. 실제 요율은 [Feezless에 문의](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)하세요.

## 고객이 상품을 선택하고 장바구니에 담도록 하고 싶으신가요?

고객이 한 페이지에서 상품을 둘러보고, 장바구니에 담고, 결제하도록 하려면 [상품 메뉴 (Product Menu)](/ko/solutions/product-menu/index) 서비스를 참고하세요.

export const PricingCalculator = () => {
  const [amount, setAmount] = useState("1000");
  const rate = 2.0;
  const value = Number(amount);
  const percent = rate;
  const fee = value * (percent / 100);
  const remainder = value - fee;
  const valid = amount.trim() !== "" && Number.isFinite(value) && value >= 0 && Number.isFinite(fee) && Number.isFinite(remainder);
  const format = (n) => n.toLocaleString("ko-KR", { minimumFractionDigits: 2, maximumFractionDigits: 2 });
  return (
    <div className="not-prose" style={{ border: "1px solid rgba(127,127,127,.25)", borderRadius: 12, padding: 16, background: "transparent", color: "inherit", width: "100%", boxSizing: "border-box" }}>
      <div style={{ display: "grid", gap: 12 }}>
        <label style={{ display: "grid", gap: 4, fontSize: 14 }}>
          결제 금액 (통화 단위)
          <input type="number" min="0" step="any" value={amount} onChange={(e) => setAmount(e.target.value)} style={{ width: "100%", minWidth: 0, padding: "8px 10px", borderRadius: 8, border: "1px solid rgba(127,127,127,.35)", background: "transparent", color: "inherit", boxSizing: "border-box" }} />
        </label>
        <div style={{ fontSize: 14 }}>
          고정 예시 수수료율(승인되지 않음): {rate}%
        </div>
        <div aria-live="polite" style={{ fontSize: 14 }}>
          {!valid ? (
            <div>유효한 결제 금액을 입력하세요.</div>
          ) : (
            <div style={{ display: "grid", gap: 6 }}>
              <div>수수료: {format(fee)} 통화 단위</div>
              <div>이 수수료를 제외한 남은 금액: {format(remainder)} 통화 단위</div>
            </div>
          )}
        </div>
        <div style={{ fontSize: 12, opacity: 0.7 }}>표시되는 소수점 둘째 자리까지의 값은 예시를 위한 것이며 Feezless의 반올림 기준과 다를 수 있습니다. 세금 및 기타 가능한 부가 비용은 포함하지 않습니다.</div>
      </div>
    </div>
  );
};
