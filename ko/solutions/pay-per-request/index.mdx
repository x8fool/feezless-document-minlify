요청당 결제 프로토콜(True Pay-Per-Request Protocol)을 사용하면 고객에게 정액 구독을 강요하는 대신 API 요청이나 디지털 서비스 호출 단위로 과금할 수 있습니다. 고객이 요청을 보내면 시스템이 결제 조건을 확인하고, 조건이 충족되면 결과나 디지털 서비스에 접근할 수 있도록 합니다.

**활용 사례:** 사용량 기반 API 접근, 온디맨드 디지털 서비스, 사용당 과금 소프트웨어 기능, 그리고 고객이 실제로 서비스를 이용할 때만 결제하기를 원하는 사용 방식

## 작동 방식

1. 요청에 대한 가격, 수취인, 서비스 이용 조건을 정의합니다.
2. API 요청, 결제, 디지털 서비스 제공을 하나의 흐름으로 연결합니다.
3. 결제 조건이 충족되면 결과나 디지털 서비스에 접근할 수 있도록 합니다.

## 준비 사항

요청당 결제를 받기 전에 다음 정보를 준비하세요.

- 과금할 API 또는 디지털 서비스
- 고객에게 청구할 요청당 또는 사용당 가격
- 수취인 정보 및 서비스 이용 조건

계정 개설 요건 및 신청 자격은 [Feezless에 문의](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)하세요.

## 요금

고객에게 청구하는 요청당 가격과 Feezless 이용 수수료를 구분하세요. 결제 수납을 시작하기 전에 현재 거래 수수료율과 관련 비용을 [Feezless에 문의](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)하세요.

### 요금 계산 예시

본 문서에는 요청당 결제에 대한 Feezless 수수료 비율이 명시되어 있지 않습니다. Feezless에서 비율 기반 요금이 r%로 확인된다면, 유료 API 요청 건당 1,000 통화 단위를 가상 거래 금액으로 예시할 때 수수료는 다음과 같이 계산됩니다.

- 결제 금액(예시): 1,000
- 수수료율: r%
- 수수료: 1,000 x r / 100 = 10r
- 이 수수료를 제외한 남은 금액: 1,000 - 10r

이 예시는 비율 기반 요금이 적용될 경우의 가상 수치이며, 모든 서비스에 반드시 비율 요금이 적용된다는 뜻은 아닙니다. 아래 예시와 계산기는 세금 및 기타 가능한 부가 비용을 포함하지 않으며, 정산 견적서가 아닙니다. 표시되는 소수점 둘째 자리까지의 값은 예시를 위한 것이며 Feezless의 반올림 기준과 다를 수 있습니다. 실제 요율은 [Feezless에 문의](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)하세요.
