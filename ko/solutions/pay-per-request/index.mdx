True Pay-Per-Request 프로토콜을 사용하면 고객을 구독에 묶어 두는 대신 개별 API 요청이나 디지털 서비스 호출 단위로 과금할 수 있습니다. 고객이 요청을 보내면 결제 조건이 평가되고, 조건이 충족되면 디지털 응답이나 서비스가 제공됩니다.

**활용 사례:** 사용량 기반 API 접근, 온디맨드 디지털 서비스, 사용당 과금 소프트웨어 기능, 그리고 고객이 실제로 서비스를 이용할 때만 결제하기를 선호하는 모든 워크플로.

## 작동 방식

1. 요청에 대한 가격, 수취인, 서비스 약관을 정의합니다.
2. API 요청, 결제, 디지털 제공을 하나의 흐름으로 연결합니다.
3. 결제 조건이 충족되면 디지털 응답이나 서비스를 제공합니다.

## 최소 준비 사항

요청당 결제를 받기 전에 다음을 준비하세요.

- 과금할 API 또는 디지털 서비스
- 고객에게 부과할 요청당 또는 사용당 가격
- 제공하는 서비스의 수취인 및 서비스 약관

계정 요건 및 이용 자격은 [hello@feezless.cloud](mailto:hello@feezless.cloud)로 문의하세요.

## 요금

고객에게 부과하는 요청당 가격과 Feezless 이용 수수료를 구분하세요. 결제를 받기 전에 현재 거래 요율과 적용되는 요금을 Feezless에 문의하세요.

> **참고:** 결제 요청을 생성하거나 이체 증빙을 받는 것만으로는 결제가 확인되지 않습니다. 디지털 응답이나 서비스를 제공하기 전에 확인된 결제 상태를 점검하세요.
