POS 판매 시스템(POS Cashier)을 사용하면 전용 결제 단말기를 구매하지 않고도 휴대폰이나 태블릿에서 바로 매장 주문과 결제를 받을 수 있습니다. 각 거래가 완료될 때마다 매출이 기록되고 재고가 자동으로 업데이트됩니다.

## 활용 사례

- 카운터, 노점, 팝업 매장에서의 매장 판매
- 고정 결제 단말기를 사용하기 어려운 경우의 모바일 결제
- 매장 판매량에 맞춘 재고 업데이트

## 작동 방식

1. 판매할 상품과 가격을 설정합니다.
2. 주문을 받고 휴대폰이나 태블릿으로 고객에게 결제 화면을 보여 줍니다.
3. 고객이 결제 화면에서 결제 수단을 선택합니다.
4. 판매가 완료되면 재고가 자동으로 차감됩니다.

> **참고:** 결제를 생성하거나 이체 증빙을 보내는 것만으로는 결제가 확인되지 않습니다. 상품이나 서비스를 제공하기 전에 확인된 결제 상태를 점검하세요.

## 준비 사항

시작하기 전에 다음을 준비하세요.

- 계산대 화면으로 사용할 휴대폰 또는 태블릿
- 판매할 상품 목록과 가격

### 요금 계산 예시

아래 수치는 이해를 돕기 위한 예시이며 승인된 요율이 아닙니다.

- 결제 금액(예시): 1,000 통화 단위
- 고정 예시 수수료율(승인되지 않음): 0.8%
- 수수료: 1,000 x 0.8 / 100 = 8 통화 단위
- 이 수수료를 제외한 남은 금액: 1,000 - 8 = 992 통화 단위

아래 예시와 계산기는 세금 및 기타 가능한 부가 비용을 포함하지 않으며, 정산 견적서가 아닙니다. 표시되는 소수점 둘째 자리까지의 값은 예시를 위한 것이며 Feezless의 반올림 기준과 다를 수 있습니다. 실제 요율은 [Feezless에 문의](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)하세요.

## 판매 채널 선택

POS 판매 시스템은 매장 고객 판매용으로 설계되었습니다. 고객이 온라인으로도 상품을 둘러보고 결제하도록 하려면 [상품 메뉴 (Product Menu)](/ko/solutions/product-menu/index)를 사용하여 스토어, 장바구니, 결제를 한 페이지에 통합하세요.

설정 및 요금 관련 문의는 사용 방식을 기재하여 [Feezless에 연락](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)하세요.

  const valid = amount.trim() !== "" && Number.isFinite(value) && value >= 0 && Number.isFinite(fee) && Number.isFinite(remainder);
  const format = (n) => n.toLocaleString("ko-KR", { minimumFractionDigits: 2, maximumFractionDigits: 2 });

        </div>

      </div>
    </div>
  );
};
