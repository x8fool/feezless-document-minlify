## 작동 방식

각 솔루션을 열어 워크플로, 준비 체크리스트, 요금 정보를 확인하세요. 계정 요건과 현재 요율은 Feezless에 문의하세요. Checkout Cart와 POS에 표시된 수수료는 예시일 뿐이며 견적 가격이 아닙니다.

## True Pay-Per-Request 프로토콜

**활용 사례:** 유료 API 요청 및 디지털 서비스 접근.

구독을 요구하는 대신 개별 API 요청 단위로 결제할 수 있게 합니다. 결제 조건이 충족되면 디지털 응답이나 서비스를 제공합니다.

- 요청 또는 사용 단위로 과금합니다.
- 요청, 결제, 디지털 제공을 하나의 흐름으로 연결합니다.
- 프로토콜에 가격, 수취인, 서비스 약관을 포함합니다.

## 결제 링크

**활용 사례:** 대화, 소셜 게시물, 웹사이트에서 결제 수납.

결제 링크를 만들어 고객이 이미 있는 곳에 공유하세요. 고객은 링크를 열어 결제하고, 판매자는 결제 상태를 추적합니다.

- 채팅, 소셜 미디어 또는 웹사이트에 링크를 공유합니다.
- 상품 카탈로그를 만들지 않고도 결제를 받습니다.
- 수납 완료 및 미수 금액을 실시간으로 확인합니다.

## 상품 메뉴

**활용 사례:** 상품 카탈로그, 레스토랑 메뉴, 카페, 소매 매장.

상품을 단일 페이지 스토어로 구성하세요. 고객은 페이지를 이동하지 않고 메뉴를 둘러보고, 장바구니에 상품을 담고, 결제를 완료합니다.

- 온라인 메뉴에 상품을 표시합니다.
- 둘러보기, 장바구니, 결제를 한곳에서 처리합니다.
- 판매가 완료되면 재고를 자동으로 차감합니다.

## POS 계산대

**활용 사례:** 휴대폰이나 태블릿을 이용한 대면 판매.

전용 결제 단말기를 구매하지 않고 모바일 기기를 계산대로 사용하세요. 판매할 때마다 매출을 기록하고 재고를 업데이트합니다.

- 휴대폰이나 태블릿으로 주문과 결제를 받습니다.
- 결제 시 고객이 원하는 결제 수단을 지원합니다.
- 판매할 때마다 재고를 자동으로 차감합니다.

## 멤버십 및 로열티

**활용 사례:** 결제 시점에 고객을 멤버십 프로그램에 등록.

고객의 첫 결제로 멤버십 카드를 발급하고 고객이 선택한 채널로 전달합니다. 고객은 링크를 통해 PIN 설정과 PDPA 동의를 직접 완료합니다.

- 결제 흐름의 일부로 멤버십 카드를 생성합니다.
- 고객에게 디지털 카드를 보냅니다.
- 고객이 직접 PIN을 설정하고 동의를 제공하도록 합니다.

## 청구서 및 요금 결제

**활용 사례:** 고객 청구 및 미수금 후속 관리.

청구서를 만들고 고객에게 결제 링크를 보내세요. 고객은 온라인으로 결제하고, 판매자는 어떤 청구서가 결제되었고 어떤 청구서가 미결제 상태인지 추적합니다.

- 별도의 문서를 수작업으로 준비하지 않고 청구서를 생성하고 발송합니다.
- 고객에게 온라인 결제 링크를 제공합니다.
- 결제 상태를 실시간으로 모니터링합니다.
