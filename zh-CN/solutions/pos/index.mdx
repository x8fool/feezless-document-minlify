门店收银系统（POS Cashier）让您直接使用手机或平板电脑接收线下订单和付款，无需购买专用收银机。每完成一笔交易，系统都会自动记录销售额并更新库存。

## 适用场景

- 在柜台、摊位或临时销售点进行线下销售
- 不便使用固定收银终端时的移动收款
- 使库存与线下门店销售保持同步

## 工作原理

1. 设置您要销售的商品清单和价格
2. 在手机或平板电脑上接单，并向客户展示支付页面
3. 客户在支付页面选择支付方式
4. 销售完成后系统自动扣减库存

> **注意：** 仅创建付款记录或发送转账凭证并不代表付款已确认。请在交付商品或服务前核实已确认的付款状态。

## 准备事项

开始使用前，请准备以下内容：

- 用作收银界面的手机或平板电脑
- 您要销售的商品清单和价格

如需了解开户要求和申请资格，请[联系 Feezless](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)。

## 费用

在开始收款前，请[联系 Feezless](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1) 了解当前交易费率和相关费用。

以下仅为帮助理解的示例：一笔 1,000 货币单位的交易，按 0.8% 的示例费率计算，手续费为 8 货币单位。此费率并非核准费率，请在开始使用前[向 Feezless 确认实际费率](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)。

### 定价计算示例

以下示例金额仅为演示用途，不代表服务价格。

| 项目 | 数值 |
| --- | --- |
| 付款金额 | 1,000 |
| 费率 | 0.8% |
| 手续费 | 1,000 × 0.8 ÷ 100 = 8 |
| 扣除该手续费后剩余 | 1,000 − 8 = 992 |

此表未包含税费及其他可能存在的费用，仅供参考，不作为结算依据。以上数字保留两位小数仅为示例参考。

## 选择销售渠道

门店收银系统专为面向到店客户的销售设计。如果您还希望客户在线浏览商品和付款，请使用[商品菜单（Product Menu）](/zh-CN/solutions/product-menu/index)，将店铺、购物车和支付整合在同一页面中。

如有设置和费用方面的问题，请[联系 Feezless](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)，并说明您的使用场景。

export const PricingCalculator = () => {
  const [amount, setAmount] = useState("1000");
  const feeRate = 0.8;
  const value = Number(amount);
  const fee = value * (feeRate / 100);
  const remainder = value - fee;
  const valid = amount.trim() !== "" && Number.isFinite(value) && value >= 0 && Number.isFinite(fee) && Number.isFinite(remainder);
  const format = (n) => n.toLocaleString("zh-CN", { minimumFractionDigits: 2, maximumFractionDigits: 2 });
  return (
    <div className="not-prose" style={{ border: "1px solid rgba(127,127,127,.25)", borderRadius: 12, padding: 16, background: "transparent", color: "inherit", width: "100%", boxSizing: "border-box" }}>
      <div style={{ fontWeight: 600, marginBottom: 12 }}>手续费试算器（示例）</div>
      <label style={{ display: "grid", gap: 6, fontSize: 14 }}>
        交易金额
        <input type="number" min="0" step="any" value={amount} onChange={(e) => setAmount(e.target.value)} style={{ border: "1px solid rgba(127,127,127,.35)", borderRadius: 8, padding: "8px 10px", background: "transparent", color: "inherit", width: "100%", minWidth: 0, boxSizing: "border-box" }} />
      </label>
      <div style={{ marginTop: 10, fontSize: 14 }}>固定示例费率: {feeRate}%（非核准费率）</div>
      <div aria-live="polite" style={{ marginTop: 12, fontSize: 15, display: "grid", gap: 6 }}>
        {valid ? (
          <>
            <div>手续费（约）: {format(fee)} 单位</div>
            <div>扣除该手续费后剩余: {format(remainder)} 单位</div>
          </>
        ) : (
          <div>请输入有效的交易金额以计算手续费。</div>
        )}
      </div>
      <div style={{ marginTop: 10, fontSize: 12, opacity: 0.75 }}>未包含税费及其他可能存在的费用。以上数字保留两位小数仅为示例参考，不代表 Feezless 的进位规则或结算金额。</div>
    </div>
  );
};
