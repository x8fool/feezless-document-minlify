Feezless 会员功能将客户的首次付款与您的会员计划关联起来。通过客户选择的渠道发放数字会员卡，然后让客户通过链接完成 PIN 设置和 PDPA 同意。

## 何时使用会员功能

使用会员功能，可在支付流程中为付费客户办理会员并发放数字会员卡。它适合希望客户自行完成 PIN 设置和同意步骤，而非由员工代为完成的企业。

## 最低准备

与 Feezless 沟通设置事宜时，请准备好以下信息：

- 您希望客户加入的会员计划。
- 您希望在数字会员卡上展示的信息。
- 您希望客户通过何种方式接收会员卡和设置链接。

这些内容有助于您准备会员流程。如需了解账户要求和可用的会员卡发送方式，请联系 [hello@feezless.cloud](mailto:hello@feezless.cloud)。

## 工作原理

1. 客户的首次付款启动会员流程。
2. 在该流程中发放数字会员卡。
3. 会员卡通过客户选择的渠道发送。
4. 客户通过链接自行设置 PIN 并提供 PDPA 同意。

请将付款确认与 PIN 设置和同意步骤分开处理。支付链接被创建或打开，并不表示客户已经付款。
