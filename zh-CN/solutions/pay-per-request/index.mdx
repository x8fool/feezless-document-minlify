真正按请求付费协议让您可以针对每一次 API 请求或数字服务调用收费，而不必让客户绑定订阅。客户发起请求后，系统会评估支付条件，并在条件满足后解锁数字响应或服务。

**适用场景：** 按量计费的 API 访问、按需数字服务、按次使用的软件功能，以及客户更希望仅在实际使用服务时付费的任何工作流程。

## 工作原理

1. 为请求定义价格、收款方和服务条款。
2. 在同一流程中连接 API 请求、支付和数字交付。
3. 在满足支付条件时解锁数字响应或服务。

## 最低准备

开始接受按请求付费的付款前，请准备以下内容：

- 您要收费的 API 或数字服务。
- 您向客户收取的每次请求或每次使用的价格。
- 您所提供服务的收款方和服务条款。

如需了解账户要求和资格条件，请联系 [hello@feezless.cloud](mailto:hello@feezless.cloud)。

## 定价

请区分您按请求向客户收取的价格与使用 Feezless 的费用。在开始收款前，请联系 Feezless 了解当前交易费率和适用费用。

> **注意：** 仅创建支付请求或收到转账凭证并不代表付款已确认。请在交付数字响应或服务前核实已确认的付款状态。

## 下一步

如需为您的 API 或数字服务设置真正按请求付费协议，请发送邮件至 [hello@feezless.cloud](mailto:hello@feezless.cloud)，并说明您的使用场景、预期请求量以及计划的每次请求价格。
