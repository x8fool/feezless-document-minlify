按请求付费协议（True Pay-Per-Request Protocol）让您可以按每次 API 请求或数字服务调用单独收费，而无需强制客户订阅包月套餐。客户发起请求后，系统会检查支付条件，并在条件满足时开放结果或数字服务的访问权限。

**适用场景：** 按使用量计费的 API 访问、按需调用的数字服务、按次收费的软件功能，以及客户希望仅在实际使用服务时付费的使用模式。

## 工作原理

1. 为请求设定价格、收款方和服务条款
2. 在同一流程中连接 API 请求、支付和数字服务交付
3. 在满足支付条件时开放结果或数字服务的访问权限

## 准备事项

开始按请求收款前，请准备以下信息：

- 需要收费的 API 或数字服务
- 向客户收取的每次请求或每次使用的价格
- 收款方信息和服务条款

如需了解开户要求和申请资格，请[联系 Feezless](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)。

## 费用

请将您按请求向客户收取的价格与使用 Feezless 的手续费区分开来。在开始收款前，请[联系 Feezless](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1) 了解当前交易费率和相关费用。

> **注意：** 仅创建支付请求或收到转账凭证并不代表付款已确认。请在交付结果或数字服务前核实已确认的付款状态。

## 下一步

如需为您的 API 或数字服务设置按请求付费协议，请[联系 Feezless](https://makeform.ai/e/iY978F0d?__mf_modal_embed=1)，并说明您的使用场景、预期请求量以及计划的每次请求价格。
