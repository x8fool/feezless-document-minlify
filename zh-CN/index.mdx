## 真正按请求付费协议

**适用场景：** 付费 API 请求和数字服务访问。

让每一次 API 请求都可单独付费，而无需订阅。在满足支付条件时解锁数字响应或服务。

- 按请求或使用次数收费。
- 在同一流程中连接请求、支付和数字交付。
- 在协议中包含定价、收款方和服务条款。

## 支付链接

**适用场景：** 通过对话、社交媒体帖子和网站收款。

创建支付链接，并在客户常用的渠道中分享。客户打开链接即可付款，您可以跟踪付款状态。

- 在聊天、社交媒体或网站上分享链接。
- 无需搭建商品目录即可收款。
- 实时查看已收款和待收款项。

## 商品菜单

**适用场景：** 商品目录、餐厅菜单、咖啡馆和零售店铺。

将您的商品集中到单页在线店铺中。客户浏览菜单、将商品加入购物车，并在不切换页面的情况下完成支付。

- 在在线菜单中展示商品。
- 将浏览、购物车和结账整合在一起。
- 销售完成后自动扣减库存。

## POS 收银台

**适用场景：** 使用手机或平板电脑进行线下销售。

将移动设备用作收银界面，无需购买专用收银设备。在销售过程中记录交易并更新库存。

- 通过手机或平板电脑接单和收款。
- 在结账时支持客户选择的支付方式。
- 每笔销售自动扣减库存。

## 会员与忠诚度

**适用场景：** 在客户付款时将其加入您的会员计划。

根据客户的首次付款发放会员卡，并通过客户选择的渠道发送。客户可通过链接自行完成 PIN 设置和 PDPA 同意。

- 在支付流程中创建会员卡。
- 将数字会员卡发送给客户。
- 让客户自行设置 PIN 并提供同意。

## 发票与账单支付

**适用场景：** 向客户开具账单并跟进待付款项。

创建发票并向客户发送支付链接。客户在线付款，您可以跟踪哪些发票已付款、哪些仍未支付。

- 创建并发送账单，无需另行手动准备单据。
- 为客户提供在线付款链接。
- 实时监控付款状态。
